Cute GPA Calculator 🎀
A simple, beginner-friendly web app that helps students calculate their GPA in a fun and aesthetic way.
Features include:

Light pink background for a cute vibe 🌸
Floating math emojis ➕➗🧮📐
GPA calculation based on entered courses, credits, and grades
Supports 4.0 and 5.0 GPA scales
Instant result message with emoji feedback 🌟👍💪


✅ How to Use

Enter your course name, credits, and letter grade.
Add more courses using Add Course.
Click Calculate GPA to see your result.
Use Clear to reset the table.
